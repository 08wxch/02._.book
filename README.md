## ขั้นตอนการซื้อคอร์ส

1. ผู้ปกครองกด **ซื้อคอร์สนี้** → กรอกชื่อนักเรียนจริง
2. หน้าชำระเงินแสดง **QR พร้อมเพย์** (สร้างจากเบอร์ที่ตั้งไว้ + ฝังยอดเงินให้อัตโนมัติ)
3. อัปโหลดสลิป → สถานะเป็น `รอยืนยัน`
4. เจ้าของเข้า `#/admin` → แท็บ **รอยืนยัน** → ดูสลิป / **ดาวน์โหลดสลิป** / กด **ยืนยัน**
5. เมื่อยืนยัน → **ไฟล์สลิปถูกลบออกจาก Supabase Storage ทันที** (เก็บไว้แค่ยอดเงิน/วันที่/สถานะ)

## ตะกร้าและการชำระเงิน

- กดซื้อคอร์ส → ต้องกด **ยืนยันเลือกคอร์ส** (ปุ่มดำ) หรือ **ไม่ซื้อคอร์ส** (ปุ่มแดง) ก่อน
- หลังอัปสลิป ปุ่มจะเป็นสีเขียว **ยืนยันการจ่ายเงิน**
- `#/cart` รวมทุกคอร์สที่เลือกไว้ แยกสถานะ: ยังไม่ได้จ่ายเงิน / รอยืนยัน / จ่ายเงินแล้ว (ลบรายการที่ยังไม่จ่ายได้)
- เฉพาะเจ้าของคำสั่งซื้อเท่านั้นที่อัปสลิป/แก้สถานะได้ (เจ้าของระบบยืนยันผ่านหลังบ้านเท่านั้น)

## บัตรส่วนลด (คูปอง)

1. **เจ้าของ** กด **+ สร้างบัตรส่วนลด** ที่ `#/admin` → แท็บ **บัตรส่วนลด**: กด "สุ่มโค้ด" หรือพิมพ์เอง, ตั้งชื่อบัตร, แนบรูปบัตร (แนะนำ 1000×560 px), ลดเป็น % หรือจำนวนเงิน,
   ยอดขั้นต่ำ, จำนวนครั้งที่ใช้ได้, เลือกได้ว่าจะให้ใช้กับคอร์สไหน (ไม่เลือก = ทุกคอร์ส), วันหมดอายุ
2. **ผู้ปกครอง** ไปที่ `#/coupons` → กรอกโค้ด → เก็บเข้ากระเป๋า ("บัตรส่วนลดของฉัน")
3. ตอนซื้อคอร์ส เลือกบัตรในช่อง **ใช้บัตรส่วนลด** → ระบบคิดส่วนลดให้ (คำนวณฝั่งเซิร์ฟเวอร์)
4. ใช้แล้วสถานะเปลี่ยนเป็น "ใช้แล้ว" ใช้ซ้ำไม่ได้

## รายชื่อนักเรียน (เจ้าของ/ครู)

- `#/students` — รายการนักเรียน (ชื่อนักเรียนเป็นหลัก) ด้านหลังเป็นปุ่มชื่อผู้ปกครองที่ผูกอยู่
- เจ้าของกรองตามหน่วยงาน/โรงเรียนได้ · ครูเห็นเฉพาะหน่วยงานตัวเอง
- กดชื่อนักเรียน → ดูคะแนน/กราฟ/ชุดข้อสอบเหมือนที่ผู้ปกครองเห็น + แผง "บัญชีผู้ปกครองที่ผูกไว้" ด้านขวา
- เพิ่มผู้ปกครอง: กด "+ เพิ่มผู้ปกครอง" → เลือกจากรายชื่อผู้ปกครอง (ค้นหาได้) · ถอดได้ทุกเมื่อ
- ลบผู้ปกครอง: กดชื่อผู้ปกครอง → ดูข้อมูล + แก้โรงเรียน + ดู/เปลี่ยนรหัสผ่าน + **ลบบัญชี** (ลบข้อมูลทั้งหมดออกจาก Supabase)
- 1 นักเรียนผูกผู้ปกครองได้หลายบัญชี · ลบผู้ปกครองไม่กระทบบัญชีนักเรียน

## หน้าคะแนนนักเรียน

- ต้องผูกนักเรียนให้ผู้ปกครองก่อน (`#/admin` → แท็บ **นักเรียน** หรือให้ครูผูกใน `#/portal`)
- หน้าภาพรวม: การ์ดสรุป (ทำแล้ว/เฉลี่ย/พัฒนาการ) + **กราฟเส้นพัฒนาการ** + รายการชุดข้อสอบ
- กด "ดูข้อที่ผิด" → เปิด **หน้าโจทย์แยก** (`#/scores/:student/exam/:exam`) จึงจะเห็นโจทย์ทีละข้อ
- โจทย์/ตัวเลือก/เฉลย เรนเดอร์ **LaTeX ด้วย KaTeX** (ไฟล์ใน `assets/vendor/katex/`)
- เคารพการตั้งค่าของชุดสอบใน 02._.mock: ถ้าครูยังไม่ประกาศคะแนน/เฉลย ระบบจะไม่แสดง
- ถ้ายังไม่มีนักเรียน จะขึ้นว่า *"ติดต่อ Line : 617806696 หรือครูในโรงเรียนเพื่อเพิ่มข้อมูลนักเรียนของท่าน"*

## แก้ข้อมูล / ตั้งค่า

- **พร้อมเพย์ + เบอร์ติดต่อ** → `#/admin` → แท็บ **ตั้งค่า** (เก็บในตาราง `bk_settings`)
- **คอร์ส** → `#/admin` → แท็บ **คอร์สเรียน** (มีติ๊ก "ไม่จำกัดจำนวนคน" สำหรับคอร์สที่ไม่จำกัดที่นั่ง)
- **บัตรส่วนลด** → `#/admin` → แท็บ **บัตรส่วนลด**
- **ผูกนักเรียน** → `#/admin` → แท็บ **นักเรียน** (เลือกผู้ปกครอง + นักเรียนจาก 02._.mock)
- **ดูรหัสผ่านผู้ปกครอง** → `#/admin` → แท็บ **ผู้ใช้งาน** (เก็บใน `bk_accounts.password_plain`)

## ตารางที่ใช้ (ทั้งหมดนำหน้า `bk_`)

| ตาราง | เก็บอะไร |
| --- | --- |
| `bk_accounts` | บัญชีของเว็บนี้ (owner / teacher / parent) + ข้อมูลติดต่อ |

| `bk_settings` | พร้อมเพย์ + ข้อมูลติดต่อ |

`bk_student_report()` (รายงานคะแนน), `bk_roster()`, `bk_teacher_link_student()`, `bk_course_seats()`

Storage buckets: `bk-slips` (ส่วนตัว), `bk-covers` (สาธารณะ)
