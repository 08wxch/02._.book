## ขั้นตอนการซื้อคอร์ส

1. ผู้ปกครองกด **ซื้อคอร์สนี้** → กรอกชื่อนักเรียนจริง
2. หน้าชำระเงินแสดง **QR พร้อมเพย์** (สร้างจากเบอร์ที่ตั้งไว้ + ฝังยอดเงินให้อัตโนมัติ)
3. อัปโหลดสลิป → สถานะเป็น `รอยืนยัน`
4. เจ้าของเข้า `#/admin` → แท็บ **รอยืนยัน** → ดูสลิป / **ดาวน์โหลดสลิป** / กด **ยืนยัน**
5. เมื่อยืนยัน → **ไฟล์สลิปถูกลบออกจาก Supabase Storage ทันที** (เก็บไว้แค่ยอดเงิน/วันที่/สถานะ)

## หน้าคะแนนนักเรียน

- ต้องผูกนักเรียนให้ผู้ปกครองก่อน (`#/admin` → แท็บ **นักเรียน** หรือให้ครูผูกใน `#/portal`)
- แสดง: คะแนนล่าสุด → กราฟพัฒนาการ (เก่าสุด → ล่าสุด) → รายการชุดข้อสอบทั้งหมด → กดดูรายข้อว่าผิดข้อไหน
- เคารพการตั้งค่าของชุดสอบใน 02._.mock: ถ้าครูยังไม่ประกาศคะแนน/เฉลย ระบบจะไม่แสดง
- ถ้ายังไม่มีนักเรียน จะขึ้นว่า *"ติดต่อ Line : 617806696 หรือครูในโรงเรียนเพื่อเพิ่มข้อมูลนักเรียนของท่าน"*

## แก้ข้อมูล / ตั้งค่า

- **พร้อมเพย์ + เบอร์ติดต่อ** → `#/admin` → แท็บ **ตั้งค่า** (เก็บในตาราง `bk_settings`)
- **คอร์ส** → `#/admin` → แท็บ **คอร์สเรียน**
- **ผูกนักเรียน** → `#/admin` → แท็บ **นักเรียน** (เลือกผู้ปกครอง + นักเรียนจาก 02._.mock)
- **ดูรหัสผ่านผู้ปกครอง** → `#/admin` → แท็บ **ผู้ใช้งาน** (เก็บใน `bk_accounts.password_plain`)

## ตารางที่ใช้ (ทั้งหมดนำหน้า `bk_`)

| ตาราง | เก็บอะไร |
| --- | --- |
| `bk_accounts` | บัญชีของเว็บนี้ (owner / teacher / parent) + ข้อมูลติดต่อ |
| `bk_courses` | คอร์สที่ขาย |
| `bk_orders` | คำสั่งซื้อ + สถานะ + path ของสลิป |
| `bk_parent_students` | ผู้ปกครอง ↔ นักเรียน (อ้าง `students[].id` ใน 02._.mock) |
| `bk_settings` | พร้อมเพย์ + ข้อมูลติดต่อ |

ฟังก์ชันสำคัญ: `bk_signup_parent()` (สมัครเองไม่พึ่งอีเมล), `bk_sync_teachers()`,
`bk_student_report()` (รายงานคะแนน), `bk_roster()`, `bk_teacher_link_student()`, `bk_course_seats()`

Storage buckets: `bk-slips` (ส่วนตัว), `bk-covers` (สาธารณะ)
